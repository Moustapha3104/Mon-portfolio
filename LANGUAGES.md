# Langages utilisés dans le projet

Ce projet de portfolio utilise les langages et technologies suivants :

## Frontend
- **HTML5** : Structure des pages (`index.html`, `admin.html`).
- **CSS3** : Utilisé via le framework **Tailwind CSS** pour le design moderne et réactif.
- **JavaScript (ES6+)** : Logique client pour les interactions, la récupération des données via l'API et la gestion du panneau d'administration.

## Backend
- **JavaScript (Node.js)** : Environnement d'exécution pour le serveur.
- **Express.js** : Framework web minimaliste pour créer les points d'accès de l'API.

## Stockage des données
- **JSON** : Utilisé comme base de données légère (`db.json`) pour stocker le contenu dynamique du portfolio.
